# Daleel

Team Daleel's entry to the Sharjah Tourism Innovation Hackathon 2026 (American University of Sharjah with the Sharjah Commerce and Tourism Development Authority, 10 to 11 October 2026). Daleel (Arabic for "guide") is a web-based tourist guide for Sharjah that tells visitors when and how to visit each place, not only what is there: every stop is scored against crowd level, heat and season, and transport impact, with browser-based AR time travel at heritage sites and a dispersal dashboard for the tourism authority.

All material in this repository was produced during the hackathon, as the rules require. Commit timestamps document the timeline.
